Personal Knowledge Base Full MVP¶

说明

仍在持续迁移和构建中...

这个项目把此前讨论的所有模块合并为一个完整 MVP：

MkDocs 静态站点
+ Markdown 研究层/深度层
+ iframe HTML 交互组件
+ JSON/JSONL 轻量数据
+ 缓存层本地网页 Capture 工具
+ 删除本地缓存文件夹功能
