    A — 自主与免受支配：最终选择权

    六维专题 | Human Primitive Motives and Constraints
    返回摘要与总览 · 位置：H=(B,A,C,E,R,V)H=(B,A,C,E,R,V)H=(B,A,C,E,R,V) 中的 A 维

    摘要

    A 回答“由谁决定”，不回答“能否完成”。同一个行动者可能拥有高水平技术与资金，却受外部许可、审查、威胁或强制服从约束；也可能能够自主选择，但无资源执行。把 A 与 C 混为一谈，会使技术和制度产生的约束无法区分。

    1. 定义与分析边界

    A 以行动选择的授权、否决权和强制关系为分析对象。缺乏资源不直接表明被支配；不被禁止也不意味着实际自由无限。权利、法律与社会规范会共同决定许可边界，许可边界不等于实际可达边界。

    2. 系统论对应

    agent 可能知道自己想选择动作 aaa，也有能力执行，但其他 agent 或制度可以禁止：

    a∉Aalloweda \notin A_{\text{allowed}}a∈/Aallowed​

    这不是能力不足，而是：

    自己的 policy 被外部主体覆盖。

    因此：

    A=谁拥有最终选择权A=\text{谁拥有最终选择权}A=谁拥有最终选择权

    Crypto 最朴素的诉求主要落在这里：

    “我的资产为什么需要别人批准才能使用？”

    2.1 结构示意

    flowchart LR
    P[个人意图] --> Q{外部许可或否决}
    Q -->|允许| I[可自行选择]
    Q -->|禁止| X[选择被覆盖]

    2.2 可操作化的工程表达

    用许可动作集 Aallowed\mathcal A_{\mathrm{allowed}}Aallowed​ 表示外部限制；再与由资源和技术决定的可行动作集 Afeasible\mathcal A_{\mathrm{feasible}}Afeasible​ 区分。实际可用集合可以写成 Aactual=Aallowed∩Afeasible\mathcal A_{\mathrm{actual}}=\mathcal A_{\mathrm{allowed}}\cap\mathcal A_{\mathrm{feasible}}Aactual​=Aallowed​∩Afeasible​。这一交集仅为分析分解，不意味着现实规则是二元许可。

    3. 不可约性：反事实见证

    两种状态：

    自由但无能

    我可以任意选择，但我没有技能、资源和工具。

    A↑,C↓A\uparrow,\quad C\downarrowA↑,C↓

    有能力但不自由

    我技能极强、资源充分，但被监禁、强制服从或禁止行动。

    A↓,C↑A\downarrow,\quad C\uparrowA↓,C↑

    因此：

    A⊥CA \perp CA⊥C

    概念上对应：

    • negative liberty / sovereignty；
    • positive capacity / effectance。

    4. 复合诉求与第七维候选

    4.1 公平 / 道德：属于多人系统上的规则函数

    “不公平”通常意味着：

    • A：我的权利被侵犯；
    • V：我的价值被贬低；
    • R：互惠规则破坏；
    • B/C：资源分配受损。

    因此：

    Fairness=f(A,C,R,V,allocation rule)Fairness=f(A,C,R,V,\text{allocation rule})Fairness=f(A,C,R,V,allocation rule)

    它是多人互动规则的评价，不是 primitive constraint。

    4.2 应用分类与维度交叉

    具体情境A 的问题非 A 的问题
    资产受第三方冻结是否存在外部 veto支付系统是否稳定属于 C
    具备资格却不得进入某领域行动许可和决策权实际知识能力属于 C
    自由选择但没有设备A 可能较高目标不可达主要属于 C
    资源分配规则受到质疑权利与支配是否对等互惠、尊重与资源后果涉及 R/V/C

    5. 技术、制度与文化接口

    区块链的去许可化叙事主要针对 A，但资产使用体验仍依赖托管、合规、算力与流动性等 C 条件。一个技术可以在协议层降低 veto，同时在兑换入口、基础设施或司法层重新形成 chokepoint。因此不能从“技术自称去中心化”直接推断用户的自主权实际提高。

    6. 可检验命题与研究设计

    在资源、技能与任务难度相同的条件下，仅改变谁拥有否决权，检验用户行为及主观受支配感；再固定 veto，独立改变资源条件。若两组变化产生不同结果，支持 A/C 的区分。判定制度效果应采用具体使用场景而非宣传语。

    7. 必要假设与未定边界

    政策主权并非绝对二值；有些限制来自协调、安全或其他人的自主权益。提高个体 A 可能降低其他行动者的 A，故分析单位及利益相关者必须明确。
