    B — 身体与生物驱力：状态约束，而非生存的同义词

    六维专题 | Human Primitive Motives and Constraints
    返回摘要与总览 · 位置：H=(B,A,C,E,R,V)H=(B,A,C,E,R,V)H=(B,A,C,E,R,V) 中的 B 维

    摘要

    B 描述由具身系统产生的直接约束与奖惩信号。其核心不是生物体始终最大化寿命，而是饥渴、疼痛、睡眠、性、舒适和感官体验等身体状态能够直接改变行动优先级。将 B 压缩为“生存”会系统性遗漏不以死亡风险为前提的动机。

    1. 定义与分析边界

    B 的分析单位是个体身体及其可承受状态。药品、居住条件、工作时长和气候属于外部影响因素，不是 B 的同义词；技能、资金属于 C，许可与强制属于 A。生理机制与文化形成的偏好可以相互影响，不能仅因行为伴随身体感觉便全部归入 B。

    1.1 维度定义的理论依据

    “生存”只能很好解释：

    • 饥饿；
    • 口渴；
    • 疾病；
    • 疼痛；
    • 温度；
    • 直接生命威胁。

    但人类存在大量由身体直接产生、却不等于“避免死亡”的驱力：

    • 睡眠；
    • 性；
    • 舒适；
    • 疼痛规避；
    • 活动与休息；
    • 感官刺激；
    • 生殖相关动机。

    行为神经科学通常把 food、water、sex、social interaction 等作为基本 motivated behavior 来研究，而 homeostasis 只覆盖其中一部分。12

    因此，更底层的定义应是：

    B=Embodied / Biological Drive\boxed{B=\text{Embodied / Biological Drive}}B=Embodied / Biological Drive​

    即：

    身体本身对 agent 施加的状态约束、驱力和奖惩信号。

    “活下去”只是 B 中最强的一部分。

    2. 系统论对应

    任何 agent 首先都有一个内部状态 xxx。

    对于生物体，存在一个可生存/可承受区域：

    x∈Ωviablex \in \Omega_{\text{viable}}x∈Ωviable​

    饥饿、疼痛、缺氧、极端温度等，本质上是在告诉 agent：

    x→∂Ωviablex \rightarrow \partial\Omega_{\text{viable}}x→∂Ωviable​

    因此 B 是：

    内部状态约束。

    2.1 结构示意

    flowchart LR
    S[身体状态变化] --> P[驱力或不适信号]
    P --> D[行动优先级]
    D --> F[状态反馈]
    F --> S

    2.2 可操作化的工程表达

    可以将身体状态与可承受区域的距离作为局部代理变量：dB(x)=dist(x,Ωviable)d_B(x)=\mathrm{dist}(x,\Omega_{\mathrm{viable}})dB​(x)=dist(x,Ωviable​)。但此式不能涵盖性驱力、愉悦和新奇感官刺激，也不能将痛感简单等同于身体损伤。跨情境研究必须把生存风险与非生存驱力分别观测。

    3. 不可约性：反事实见证

    设一个人：

    • 自由；
    • 极有能力；
    • 对环境完全了解；
    • 被深爱；
    • 觉得人生非常有意义；

    但正在经历：

    • 极端疼痛；
    • 窒息；
    • 饥渴；
    • 严重睡眠剥夺。

    其他五维无法消除身体直接产生的驱力。

    因此：

    B⊈A+C+E+R+VB \not\subseteq A+C+E+R+VB⊆A+C+E+R+V

    4. 复合诉求与第七维候选

    4.1 性与繁衍：主要属于 B + R

    Fundamental Social Motives Framework 会将 mate acquisition、mate retention、kin care 分别建模，因为它研究的是具体进化适应问题。3

    但我们的目标是更高层级的最小生成基。

    因此：

    Sex / mating≈B+R+Vsocial\text{Sex / mating}\approx B+R+V_{\text{social}}Sex / mating≈B+R+Vsocial​ parenting≈B+R+V\text{parenting}\approx B+R+Vparenting≈B+R+V

    没有必要继续拆成独立轴。

    4.2 安全：是多维状态，不是 primitive

    安全可能来自：

    Safety≈B+A+C+ESafety\approx B+A+C+ESafety≈B+A+C+E
    • B：身体不会受损；
    • A：别人不能任意支配我；
    • C：我有防御和逃离能力；
    • E：威胁可被识别和预测。

    因此“安全”非常重要，但不是最低层基向量。

    4.3 应用分类与维度交叉

    具体情境首要机制与其他维度的分界
    饥饿、缺氧、严重疾病身体状态及其告警信号治疗手段是否可得是 C
    睡眠、舒适与疼痛规避生理调节及直接体验能否自行安排睡眠涉及 A
    性、繁衍与照护生理驱力与身体相关性亲密联结和照护关系涉及 R

    5. 技术、制度与文化接口

    医疗干预首先改变身体状态边界，医学诊断提高 E，治疗技术提高 C。安全型技术往往同时作用于 B、A、C、E：防护设备改善身体结果，预警系统改善认知，逃生工具增加效能，制度保障减少外部剥夺。不能仅凭“让人更安全”判断其只作用于 B。

    6. 可检验命题与研究设计

    构造控制 A/C/E/R/V 条件、但改变疼痛或睡眠状态的情境；若行为优先级仍显著变化，支持 B 在概念上不被替代。经验研究需进一步控制资源、医疗可及性和文化背景；反事实例子本身不等于独立神经回路的证明。

    7. 必要假设与未定边界

    驱力强度受年龄、环境、经验与疾病状态影响；Ωviable\Omega_{\mathrm{viable}}Ωviable​ 不存在可直接通用的单一阈值。将行为神经科学中的分类移植为此六维体系，属于解释性建模，不是该六维已获实验证实。
