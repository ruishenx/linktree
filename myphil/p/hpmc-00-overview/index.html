    人类朴素情感与约束的最小正交集：六维模型

    系列总览 | Human Primitive Motives and Constraints

    目标：不是列举所有情绪、欲望或社会动机，而是寻找一个足够小、各维度在概念上尽量不可约、又能组合解释大多数人类朴素诉求的“候选最小正交集”。

    结论：本文提出六维候选模型：

    H=(B,A,C,E,R,V)\boxed{ H=(B,A,C,E,R,V) }H=(B,A,C,E,R,V)​
    • B — Body / Biological Drive：身体与生物驱力
    • A — Autonomy：自主与免受支配
    • C — Capability / Effectance：能力与效能
    • E — Epistemic Clarity：认知与可知性
    • R — Relatedness：关系与联结
    • V — Value / Mattering：价值、重要性与意义

    最朴素的六句话：

    1. “我想让身体处在可接受的状态。”
    2. “我想自己决定。”
    3. “我想做得到。”
    4. “我想知道、看懂并预测。”
    5. “我想与别人互相联结、在乎。”
    6. “我想知道什么值得做，也希望我的存在与行动是重要的。”

    摘要

    本文讨论的是一个用于解释人类朴素诉求的候选最小正交集，而非心理学已验证的六需求定律。模型采用六维，并将其置于同一抽象层级：B 为身体状态约束，A 为选择主权，C 为干预效能，E 为认知可知性，R 为关系联结，V 为价值与重要性。核心方法是以覆盖性、不可约性、同层级、生成性和可工程化为判据，随后以反事实和技术案例进行检验。

    命题性质：六维的系统对应是建模定义；技术影响和因果机制是可供检验的推断；“恰好六维且最小”尚不是经过经验或数学证明的结论。

    1. 研究对象与概念正交

    这里研究的不是：

    • “人类一共有多少种情绪”；
    • “心理学已经证明有六种基本需要”；
    • “大脑中是否存在六套独立神经回路”。

    这里要解决的是一个工程化建模问题：

    如果把人类各种“如果……就好了”“我不想……”“我希望……”式的朴素诉求视为高维现象，能否找到一个候选最小正交集，使大量具体欲望都能由其中的基本维度组合解释？

    因此，“正交”是概念正交（conceptual orthogonality），而不是统计学意义上的零相关。

    六个维度在现实中当然会高度相关。例如贫穷可能同时损伤身体安全、自主、能力、关系和社会价值；但这不意味着它们在概念上是同一个变量。

    1.1 最小正交集的五项判据

    一个候选维度只有同时尽量满足以下条件，才应保留。

    判据 A：不可约性

    不能稳定地由其他维度推导出来。

    如果一个人其他维度全部满足，而该维度仍然可能严重缺失，则说明它有独立性。

    判据 B：覆盖性

    删除它以后，会出现一大类常见人类诉求无法自然表达。

    判据 C：同层级

    不能一会儿列“生存”，一会儿列“金钱”，一会儿列“爱情”，因为三者抽象层级不同。

    “金钱”是工具，“爱情”是具体关系形态，“生存”是结果。

    判据 D：生成性

    应当能够组合解释大量上层概念，例如：

    • 安全；
    • 自由；
    • 成就；
    • 好奇；
    • 爱；
    • 地位；
    • 公平；
    • 金钱；
    • 意义；
    • 身份；
    • 宗教；
    • 娱乐。

    判据 E：可工程化

    最好能映射到一个一般性的 agent / control-system 模型，而不仅是自然语言分类。

    2. 六维模型

    维度英文最朴素的问题主要约束来源典型缺失感
    BBody / Biological Drive我的身体是否处于可接受状态？生理系统、身体、疾病、自然环境饿、渴、痛、疲劳、性驱力、恐惧
    AAutonomy我能否自己决定？其他行动者、组织、制度的 veto / coercion被控制、被强迫、被禁止
    CCapability / Effectance我能否让想要的结果发生？技能、资源、工具、时间、因果控制力无力、不会、没资源、做不到
    EEpistemic Clarity我知道真实状态、原因和未来吗？信息缺失、噪声、复杂性、不确定性困惑、未知、不可预测
    RRelatedness我和别人是否存在真实而稳定的联结？社会网络中的边缺失或不可靠孤独、排斥、无人理解、失去依恋
    VValue / Mattering什么值得做？我和我的行动是否重要？价值函数、社会/自我评价、长期方向缺失空虚、无意义、无价值、无方向

    可以压缩为：

    身体可承受、选择属于我、事情做得到、世界看得懂、人与人连得上、行动值得做\boxed{ \text{身体可承受、选择属于我、事情做得到、世界看得懂、人与人连得上、行动值得做} }身体可承受、选择属于我、事情做得到、世界看得懂、人与人连得上、行动值得做​

    3. 系统论框架

    如果把人视为一个：

    嵌入身体、部分可观测、处于多行动者环境中的目标导向控制系统

    那么六维几乎可以自然对应到六种不同的约束。

    flowchart LR
    B[B 身体约束] --> P[行动者]
    A[A 选择主权] --> P
    E[E 观测与模型] --> P
    V[V 价值目标] --> P
    P --> C[C 行动效能]
    C --> W[外部世界]
    W --> E
    P --- R[R 关系网络]

    图示为分析结构，不表示六维之间的统计独立或单向因果。B/A/E/V 分别提供不同性质的约束，C 对应干预链路，R 对应多人关系。每个分维的操作定义、反事实见证与约束边界见对应专题。

    4. 反事实不可约性：方法

    严格数学意义上的“独立证明”在这里并不存在，但可以使用**反事实见证（counterexample witness）**进行概念检验：

    能否构造“其他五维都很高，但该维很低”的人类状态？

    如果可以，则该维不能轻易删除。

    逐维反事实检验及完整例子见六篇维度专题。反事实可以排除部分概念合并方案，但并不构成统计独立性或神经模块性的实验证明。

    5. 为什么不能轻易压缩为五维

    最有诱惑力的压缩有四种。

    5.1 把 E 合并进 C：失败

    理由：

    “知道”可以提高“做到”，但人存在不以外部任务成功为目标的信息寻求。

    因此 E 是独立的 epistemic reward / uncertainty-reduction channel。12

    5.2 把 A 合并进 C：失败

    理由：

    自主解决“谁决定”，效能解决“能不能实现”。

    一个是 authority / veto 问题，一个是 actuation / reachability 问题。

    5.3 把 R 与 V 合并为“社会需要”：失败

    因为：

    being loved≠being respected\text{being loved} \neq \text{being respected}being loved=being respected

    更进一步：

    mattering\text{mattering}mattering

    甚至可以存在于完全不依赖社会排名的宗教、艺术、科研和私人价值系统中。

    5.4 把 B 视为 C 的“身体资源”：失败

    饥饿、疼痛、性、睡眠等驱力不只是“执行能力下降”。

    它们本身能够直接重排 reward priority。

    因此身体不能只被当成一种工具资源。

    6. 为什么暂不增设第七维

    若继续增加，最常见候选包括：

    1. pleasure / happiness；
    2. novelty / exploration；
    3. reproduction；
    4. fairness / morality；
    5. identity；
    6. meaning / transcendence；
    7. security；
    8. care。

    重新审查后，暂时都不需要升为第七基向量。

    候选维度的完整归约检验分置于六篇专题：快乐/痛苦、意义见 V；新奇与身份见 E；性与繁衍、安全见 B；公平/道德见 A；照护见 R。相关归属是本模型提出的工作性分解，并非唯一可能分类。

    8. 技术革新分析与待验证假设

    这套六维模型尤其适合分析：

    为什么某种技术会触发大规模采用，而另一些技术即使先进却长期局限于专业领域？

    可以先完全不看技术名字，而问：

    它降低了哪一种人类基础约束？

    8.1 技术映射示例

    技术主要作用维度最朴素的情感
    农业B + C“如果不用担心没饭吃就好了。”
    医药B + E + C“如果知道哪里病了、还能治好就好了。”
    汽车C“如果我能更快去很远的地方就好了。”
    InternetE + R + C“如果我能立即知道、联系、传输就好了。”
    搜索引擎E“如果我马上能找到答案就好了。”
    SmartphoneC + E + R“如果这些能力都随身带着就好了。”
    Social MediaR + VsocialV_{\text{social}}Vsocial​“如果我能被连接、被看见就好了。”
    Bitcoin / CryptoA + C“如果别人不能随意阻止我处分自己的资产就好了。”
    AIC + E“如果我也能像专家一样做、像专家一样理解就好了。”
    宗教制度V + R + E“如果世界有解释、人生有意义、我有所归属就好了。”

    保险B + C + E“如果坏事发生时不至于毁掉一切就好了。”

    8.2 General-Purpose Technology 的一个假设

    可以提出一个待验证假设：

    一种技术越能同时、低成本、大规模地降低多个基础维度的约束，其成为 general-purpose technology 的概率越高。

    例如：

    AI

    AI→C↑+E↑AI\rightarrow C\uparrow+E\uparrowAI→C↑+E↑

    进一步通过 agent 和机器人可能影响：

    A, B, R, VA,\ B,\ R,\ VA, B, R, V

    Internet

    Internet→E↑+R↑+C↑Internet\rightarrow E\uparrow+R\uparrow+C\uparrowInternet→E↑+R↑+C↑

    Smartphone

    Smartphone→C↑+E↑+R↑Smartphone\rightarrow C\uparrow+E\uparrow+R\uparrowSmartphone→C↑+E↑+R↑

    因此，它们的社会影响通常大于只解决一个狭窄工业参数的技术。

    这只是分析假说，并非已有文献证明的定律。

    8.3 从技术属性到人类约束

    评价一项技术，应先指定作用对象、使用场景和权利边界，再判断它对六维的净效应；不能由“中心化 / 去中心化”“先进 / 落后”等技术标签直接推出社会结果。以区块链和 AI 为例，两者分别可能主要改变 A/C 与 C/E，但最终体验还取决于账户入口、基础设施、制度许可、实际可靠性和分配机制。

    因果分析建议按以下顺序展开：识别原始约束 → 确认技术直接改变哪项可达边界 → 追踪现实基础设施与 chokepoint → 判断普通人实际获得的净变化。此顺序是研究程序，不是任何技术必然普及的判据。

    flowchart LR
    N[朴素诉求] --> K[约束类型]
    K --> T[技术或制度]
    T --> D[实际可达边界]
    D --> F[反馈与再评价]

    9. 假设、边界与不确定性

    9.1 这不是“心理学已经证明的六大基本需求”

    Self-Determination Theory 最经典的是：

    Autonomy+Competence+RelatednessAutonomy+Competence+RelatednessAutonomy+Competence+Relatedness

    而 Fundamental Social Motives Framework、Maslow、ERG、Murray、DRAMMA 等采用不同的需要/动机集合。3456

    2024 年对基本心理需要测量工具的系统综述也显示，研究中出现过：

    • autonomy；
    • competence；
    • relatedness；
    • physical needs；
    • safety；
    • self-esteem；
    • novelty；
    • meaning；
    • dominance；
    • learning；
    • morality；

    等大量不同候选。6

    不存在学界公认的“唯一六维最小正交集”。

    9.2 六维是工程抽象，而不是神经解剖分区

    一个真实行为往往同时激活多个神经回路与动机系统。

    因此：

    B,A,C,E,R,VB,A,C,E,R,VB,A,C,E,R,V

    不应被理解成“大脑六个模块”。

    9.3 概念正交不等于统计独立

    现实中这些变量通常高度耦合。

    例如贫穷可以同时降低：

    B,A,C,R,VB,A,C,R,VB,A,C,R,V

    战争可以同时打击：

    B,A,C,E,R,VB,A,C,E,R,VB,A,C,E,R,V

    因此实际数据中的相关系数完全可能很高。

    9.4 最值得继续挑战的维度是 V

    V 是六维中最抽象、最容易继续拆分的维度。

    未来如果发现无法通过同一变量稳定解释：

    • intrinsic value；
    • purpose；
    • self-worth；
    • social status；
    • existential significance；

    则可能需要进一步拆成：

    V1=Value / PurposeV_1=\text{Value / Purpose}V1​=Value / Purpose V2=Social / Existential MatteringV_2=\text{Social / Existential Mattering}V2​=Social / Existential Mattering

    此时模型将从 6D 变为 7D。

    目前为了遵循“最小正交集”的建模目标，暂时不拆。

    10. 结论

    六维模型的关键不在于简单增加或删除维数，而是使各维度处于相同的系统抽象层级。

    模型表达为：

    H=(B,A,C,E,R,V)\boxed{ H=(B,A,C,E,R,V) }H=(B,A,C,E,R,V)​

    可以分别解释为：

    代码系统论含义朴素语言
    Binternal state / viability身体能不能承受？
    Apolicy sovereignty是不是我自己决定？
    Cactuation / controllability我做不做得到？
    Eobservation / world model我知不知道发生了什么？
    Rrelational edges我和别人有没有真实联结？
    Vobjective / value function什么值得做、我是否重要？

    这六维具有一个非常重要的结构优势：

    它们不只是心理学名词，而能直接对应到一个“具身、部分可观测、多行动者、目标导向 agent”的基本结构。

    从这个角度看：

    朴素情感=agent 感知到某个基本约束后的主观信号\boxed{ \text{朴素情感} = \text{agent 感知到某个基本约束后的主观信号} }朴素情感=agent 感知到某个基本约束后的主观信号​

    而技术、制度和文化的作用，则可以重新定义为：

    改变 (B,A,C,E,R,V) 中一个或多个约束的可达边界\boxed{ \text{改变 }(B,A,C,E,R,V)\text{ 中一个或多个约束的可达边界} }改变 (B,A,C,E,R,V) 中一个或多个约束的可达边界​

    因此，判断一种技术的深层社会意义时，可以不先问：

    “它是中心化还是去中心化？”

    而先问：

    “它让普通人在 B/A/C/E/R/V 哪些方向上，从‘原来做不到’变成了‘现在可以’？”
