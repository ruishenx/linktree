    C — 能力与效能：从意图到干预

    六维专题 | Human Primitive Motives and Constraints
    返回摘要与总览 · 位置：H=(B,A,C,E,R,V)H=(B,A,C,E,R,V)H=(B,A,C,E,R,V) 中的 C 维

    摘要

    C 表示将意图转化为现实状态变化的因果能力，而不只是个人智力或技能。工具、资本、时间、算力、交通和组织资源都可以改变目标状态的可达性。其与 A 的分界是“能否实现”对“谁来决定”，与 E 的分界是“能否干预”对“是否理解”。

    1. 定义与分析边界

    C 的核心指标是目标的可达集合及可重复的干预能力。资源拥有量并非最终指标：资金多、工具多不代表在具体任务中可形成有效行动。把 C 视为绝对通用能力将忽略环境与目标的差异。

    1.1 维度定义的理论依据

    “能力”容易被理解为：

    技能、知识、智力。

    但朴素的“做不到”还可能来自：

    • 没有工具；
    • 没有资金；
    • 没有算力；
    • 没有体力；
    • 没有时间；
    • 没有交通手段；
    • 没有组织能力。

    这些都不是“技能不足”，却属于同一个更抽象的问题：

    我是否拥有把意图变成现实状态变化的因果能力？

    因此，可定义为：

    C=Capability / Effectance\boxed{C=\text{Capability / Effectance}}C=Capability / Effectance​

    即：

    agent 对世界实施有效 intervention 的能力。

    这与 Self-Determination Theory 中的 competence 有明显亲缘关系，但这里的定义更工程化、更宽，包括资源和工具，而不仅是主观胜任感。12

    2. 系统论对应

    即使选择完全自由，一个人仍可能：

    想做，但做不到。

    在控制论语言中就是：

    系统是否具有足够的 controllability / actuation capability，使目标状态可达？

    xt→atxt+1x_t \xrightarrow{a_t} x_{t+1}xt​at​​xt+1​

    如果 action channel 太弱，则：

    x∗ unreachablex^* \text{ unreachable}x∗ unreachable

    AI、机器、汽车、资本、工具、教育都可以提高 C。

    2.1 结构示意

    flowchart LR
    G[目标] --> K[技能与工具]
    K --> R[资源与执行]
    R --> O[实际结果]
    O --> F[纠偏反馈]

    2.2 可操作化的工程表达

    设环境状态为 x0x_0x0​，时间窗为 TTT，工具与资源条件为 K\mathcal KK，则 R(x0,T;K)\mathcal R(x_0,T;\mathcal K)R(x0​,T;K) 表示可达状态集合。对目标 x∗x^*x∗，若 x∗∉Rx^*\notin\mathcal Rx∗∈/R，则该任务的 C 不足。该表达是控制系统的理想化，复杂社会行动未必具有完整的状态变量和动力学函数。

    3. 不可约性：反事实见证

    知道但做不到

    我完全知道怎样造火箭，但没有资金、设备与组织资源。

    E↑,C↓E\uparrow,\quad C\downarrowE↑,C↓

    做得到但不知道

    我有很强的执行机器，但不知道敌人在哪里。

    C↑,E↓C\uparrow,\quad E\downarrowC↑,E↓

    因此：

    C⊥EC \perp EC⊥E

    4. 复合诉求与第七维候选

    4.1 应用分类与维度交叉

    具体情境C 的变化主要相邻维度
    教育和训练增加可执行技能E 可同时提高
    资本、算力和工具普及扩大可实施干预范围A 仍可能限制使用
    汽车和交通网络改变空间可达性B 的体力约束可能减轻
    AI 辅助工作放大表达、分析和执行能力E 是否可靠需单独验证

    5. 技术、制度与文化接口

    一种技术的 C 效应不应仅按峰值性能衡量，应考察普通人可获得的行动边界是否扩大，以及新增能力是否被可靠地交付。AI 可能增加认知与生产效能，但是否使某项任务“真的做得到”仍取决于工具接入、验证成本、风险责任和制度授权。

    6. 可检验命题与研究设计

    在信息量与自主许可一致时，分别提供工具、训练或资金，观察目标完成概率与成本；并设置仅提供说明书而不给工具的对照组，以检验 C/E 差异。理想检验还应控制目标难度和外部协作质量。

    7. 必要假设与未定边界

    C 是任务与环境的函数而非静态人格量。技术强弱不必与最终收益线性相关，部署可靠性、反馈时滞和关键瓶颈会改变效果。
