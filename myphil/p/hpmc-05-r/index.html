    R — 关系与联结：多人网络中的边

    六维专题 | Human Primitive Motives and Constraints
    返回摘要与总览 · 位置：H=(B,A,C,E,R,V)H=(B,A,C,E,R,V)H=(B,A,C,E,R,V) 中的 R 维

    摘要

    R 不以个体在群体中的排名为核心，而是以人与人之间是否存在可持续、可信赖、互惠或照护性的联结为核心。归属、家庭、友谊和亲密关系可以在不同程度上投影到 R。社会地位则主要属于 V 的社会评价面向。

    1. 定义与分析边界

    R 的基本分析单位是行动者之间的关系边及其方向、质量和稳定性。边的存在本身不等于高质量联结；公开关注数不等于亲密关系。Care 不要求总是互惠，因此 R 应允许方向性。

    2. 系统论对应

    人在多人系统中不是孤立 node。

    关系可以表示为图：

    G=(V,E)G=(V,E)G=(V,E)

    R 关注的不是节点排序，而是：

    agent 与其他 agent 之间是否存在稳定、互惠、可信赖的边。

    例如：

    • attachment；
    • friendship；
    • family；
    • affiliation；
    • care；
    • intimacy；
    • belonging。

    因此：

    R≈edge existence + edge qualityR \approx \text{edge existence + edge quality}R≈edge existence + edge quality

    Self-Determination Theory 将 relatedness 与 autonomy、competence 分开；Fundamental Social Motives 研究也发现 affiliation、status、mate seeking、kin care 等社会动机具有区分效度。12

    2.1 结构示意

    flowchart LR
    A[个体 A] -->|照护| B[个体 B]
    B -->|信任| A
    A ---|归属| C[群体 C]

    2.2 可操作化的工程表达

    用 G=(N,L,W)G=(N,L,W)G=(N,L,W) 表示关系网络：NNN 为行动者，LLL 为关系边，WWW 可记录信任、持续性、照护或互惠等多种属性。单一标量不能同时替代所有关系质量，也不能从图中心性直接推导主观孤独感。

    3. 不可约性：反事实见证

    被爱但没有地位

    一个人可以拥有：

    • 配偶；
    • 家人；
    • 好朋友；

    同时没有：

    • 权威；
    • prestige；
    • 社会可见性。

    有地位但没有联结

    一个人也可以：

    • 极受尊敬；
    • 权力很高；
    • 大量陌生人仰慕；

    却没有亲密可信赖关系。

    因此：

    R≠VsocialR \neq V_{\text{social}}R=Vsocial​

    关系更接近边的质量，社会地位更接近节点在评价系统中的权重。

    4. 复合诉求与第七维候选

    4.1 Care：属于 R 的有方向版本

    Relatedness 不应只定义成：

    “别人爱我。”

    而应定义为更一般的：

    attachment / affiliation / care edge\text{attachment / affiliation / care edge}attachment / affiliation / care edge

    包括：

    • 我关心别人；
    • 别人关心我；
    • 互惠联结；
    • 亲缘照护；
    • 亲密关系。

    因此 care 无需单列。

    4.2 应用分类与维度交叉

    具体情境主要关系结构不应混淆的变量
    友谊和亲密关系稳定双向联结社会声望 V
    亲缘照护可有方向性的照护义务生殖驱力 B
    群体归属群体成员身份及关系可持续性自我认同中的 E/V
    社交媒体提供连接渠道和可见性被看见不等于被理解

    5. 技术、制度与文化接口

    互联网降低建立关系边的通信成本，但关系质量不会自动随连接数增加。面对社交产品，至少要分别评价可达人数、互惠程度、信任、持续性和孤独感，避免用关注量代替 R。多人制度设计还需留意互惠规则破坏引起的 A/V 等交叉效应。

    6. 可检验命题与研究设计

    在声望、收入与资源水平相近时，比较关系稳定性或真实照护的差异；再在关系质量近似相同时改变公开地位。若两类差异对应不同的孤独感与尊重感，支持 R 与 VsocialV_{\mathrm{social}}Vsocial​ 的区分。

    7. 必要假设与未定边界

    跨文化亲密、归属与义务的表现形式不同。单一网络数据往往无法推断主观体验，也不能把所有社会动机都简化为图论边权。
